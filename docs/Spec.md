# 모바일 청첩장 — 1차 스펙 (커버 + 인사말)

## 목표

참고 영상의 첫 화면 구성을 **그대로**, 정적으로 구현한다. 오프닝 연출·타이핑 효과 없음.
업체의 이미지/코드는 사용하지 않고 CSS/SVG와 사용자 사진으로 직접 만든다.

## 기술

- Vite + React + TypeScript, 정적 빌드(Vercel 배포 예정)
- 폰트: Google Fonts `Nanum Pen Script` (가는 펜 손글씨)
- 테스트: Vitest + @testing-library/react
- 린트: ESLint (Vite 템플릿 기본)

## 화면 구성 (위→아래, 흰 배경 #fff, 콘텐츠 최대폭 430px 중앙)

### 1. 봉투 커버 `EnvelopeCoverView`

- 화면 폭의 약 72% 너비, 상단 여백 약 40px, 가운데 정렬
- **크라프트지 봉투**(베이지/연회갈색 #d9cfc0 계열, 미세한 종이 질감 — SVG feTurbulence 노이즈 등)
  - 뒷면 + 위로 **열린 덮개**(삼각형, 뒤쪽 레이어)
  - 앞쪽 **포켓**: 양옆 위 모서리에서 가운데로 V자로 살짝 내려오는 형태, 은은한 그림자로 입체감
  - 봉투 본체 비율 약 가로 1 : 세로 0.72
- **커플 사진**: 뒤판과 앞 포켓 사이에 끼워져 위로 튀어나옴 (봉투 높이의 약 45%가 위로 노출)
  - 배경 제거된 투명 PNG(`public/images/couple.png`) 사용
  - 흰색 테두리 스티커 효과: `filter: drop-shadow` 여러 겹으로 흰 외곽선 + 아주 옅은 그림자
  - 이미지가 없을 때를 위한 플레이스홀더 PNG/SVG 제공
- **포켓 위 손글씨** (Nanum Pen Script, #333, 작게)
  - 왼쪽 위: `{groomFather}·{groomMother}의 아들` / 다음 줄 들여서 `{groomName}`
  - 오른쪽 아래: `{brideFather}·{brideMother}의 딸` / 다음 줄 `{brideName}`
- **하트 스티커 1**: 사진 오른쪽 위(봉투 우상단 바깥쪽 위), 빨간색(#b3262e 계열), 흰 테두리 스티커

### 2. 인사말 `GreetingView`

- 봉투 아래 약 60px 여백 후 시작
- 가운데 정렬, Nanum Pen Script, 약 20px, 줄간격 약 1.9, 색 #222
- 문단 사이 한 줄 여백
- 마지막: `사랑을 담아♡` / `{groomName}, {brideName} 드림`
- **하트 스티커 2**: 인사말 두 번째 문단 높이, 화면 왼쪽 가장자리 근처

### 하트 움직임

- 두 하트 모두 위아래로 천천히 떠다님(약 6px, 3초 주기, ease-in-out 무한반복), 살짝 회전(±6°)
- 두 하트의 위상은 다르게
- `prefers-reduced-motion: reduce`이면 정지

## 1차 화면 확인 후 변경 사항 (참고 영상에 맞춤)

- 위로 열린 삼각 덮개 제거 — 봉투 윗변은 직선, 사진이 윗변 위로 약 48% 튀어나옴
- 봉투 폭 68%, 페이지 상단 여백 24px
- 색상: 포켓 #e8e0d3, 뒤판 #e2d9cb
- 하트 1: 36px, 오른쪽 사람 머리 위 / 하트 2: 30px
- 인사말: 17px, 줄간격 1.85, 봉투와 간격 48px
- 린트는 Vite 템플릿 기본인 oxlint 사용, 사진 플레이스홀더는 SVG

## 2차: 참고 영상 정밀 재현 (이 섹션이 위 내용보다 우선)

참고 영상 프레임을 확대해 측정한 값이다. 봉투 관련 수치는 **봉투 폭 W 기준 비율**(원점 = 봉투 좌상단 바깥 경계), 페이지 관련 수치는 **화면 폭 S 기준**이다.

### 페이지 배치

- 봉투: 폭 0.733S, 좌우 가운데, 뒤판 윗변이 화면 상단에서 약 0.44S
- 봉투 전체 높이 ≈ 0.96W (거의 정사각형)
- 회전 없음(0°)

### 봉투 형태 (정면, 위가 열린 봉투)

1. **뒤판(back)** — 윗부분이 사다리꼴
   - 윗변: x 0.095W ~ 0.905W, y 0
   - 양옆 사선: 윗변 끝에서 바깥 아래로 내려와 y 0.256W에서 봉투 전체 폭(x 0, x 1W)에 닿음
   - 그 아래로는 직사각형, 바닥 y 0.96W
   - 안쪽 면(사진 뒤로 보이는 부분)은 바깥보다 살짝 어두운 베이지
2. **사진** — 뒤판과 앞 포켓 사이
   - 가로 x 0.10W ~ 0.94W
   - 머리 꼭대기가 뒤판 윗변보다 약 0.12W 위로 튀어나옴 (사진 상단 y ≈ -0.12W)
   - 아랫부분은 포켓 뒤에 숨음 (포켓 홈 바닥 y 0.436W 아래는 가려짐)
3. **앞 포켓(pocket)** — 윗변이 **평평한 바닥의 U자 홈**
   - 양 끝 윗점: (0, 0.267W), (1W, 0.267W)
   - 왼쪽: (0, 0.267W)에서 오른쪽 아래로 사선 → x ≈ 0.17W, y ≈ 0.33W에서 둥글게 꺾여 (0.225W, 0.436W)에 닿음
   - 홈 바닥: y 0.436W, x 0.225W ~ 0.78W 수평
   - 오른쪽은 대칭: (0.78W, 0.436W)에서 둥글게 올라가 x ≈ 0.83W, y ≈ 0.33W → (1W, 0.267W)
   - 홈 가장자리에 아주 옅은 그림자(앞 포켓이 사진 위에 떠 있는 느낌)
   - 포켓 앞면에 옆날개 접힘선: 홈 바닥 높이에서 왼쪽 x 0.07W, 오른쪽 x 0.92W 근처부터 아래로 거의 수직인 아주 옅은 선. 바깥 띠는 살짝 다른 명도
   - 바닥 y 0.96W
4. **음영**: 오른쪽 가장자리와 오른쪽 아래가 약간 어둡고, 봉투 바깥 오른쪽 아래로 옅은 그림자
5. **색과 질감**: 회색빛 밝은 베이지(바깥 약 #dcd6cb, 포켓 약 #dfd9ce, 안쪽 약 #cfc7b9)
   - `public/images/kraft-paper.jpg`(Pixabay Content License, 출처 표기 불필요) 질감을 깔되, 채도를 크게 낮추고 밝혀 위 색에 맞춘다

### 손글씨 이름 (포켓 앞면)

- 글자 크기 약 13px, #333
- 신랑 부모 줄: x 0.13W, y 0.55W / 신랑 이름: x 0.26W, y 0.64W
- 신부 부모 줄: x 0.58W, y 0.76W / 신부 이름: x 0.68W, y 0.85W

### 하트 1 (봉투 위) — **큰 하트 + 작은 하트가 붙은 스티커 하나**

- 묶음 가로 약 0.174W, 중심 x ≈ 0.53W, 상단 y ≈ -0.255W
- 큰 하트는 오른쪽 위, 작은 하트(큰 하트의 약 55%)는 왼쪽 아래에 살짝 겹침
- 묶음 전체를 약 -15° 회전
- 빨강 #b5333a 계열, 크레용처럼 살짝 거친 질감, 흰 테두리 스티커

### 인사말

- 봉투 바닥에서 첫 줄까지 약 90px
- 글자 크기 약 24px, 줄 간격 약 51px, 단어 간격 넓게(약 0.3em)
- 문단 사이는 줄 간격보다 약 12px만 더 띄움
- 손으로 쓴 느낌이 나도록 **줄마다 기울기를 다르게**: 예) -4°, -1°, -4°, 0°, -2°, -3°… (데이터에서 줄별로 지정)

### 하트 2 (인사말 왼쪽)

- 하나짜리 하트, 폭 약 0.10S(≈40px), 왼쪽에서 0.078S
- 두 번째 문단 첫 줄 높이, 약 -10° 회전

### 움직임

- 하트 위아래 떠다님은 유지 (회전값은 위 기본 각도를 중심으로 ±4°)

## 3차: 사용자가 고른 봉투 이미지로 교체 (봉투 관련은 이 섹션이 2차보다 우선)

- 코드로 그린 SVG 봉투와 크라프트지 질감(`kraft-paper.jpg`, `EnvelopePaperDefsView`, `PaperTone`)은 제거
- 봉투는 사용자가 준 이미지(348×432, 배경 제거 후 2배 확대해 696×864) 두 장을 겹쳐서 표현
  - `public/images/envelope-full.png`: 봉투 전체(위로 열린 덮개, 안쪽 편지지, 앞 포켓 포함), 투명 배경
  - `public/images/envelope-pocket.png`: 같은 크기 캔버스에 **앞 포켓만** 남긴 이미지
- 레이어 순서(아래→위): envelope-full → 커플 사진 → envelope-pocket → 손글씨 이름
- 봉투 박스: 폭 0.70S, 가운데, 비율 696:864. 이하 좌표는 봉투 박스 폭·높이 기준 %
  - 포켓 입구(사진이 숨는 선): 높이의 약 65.7% 지점이 홈 바닥, 양 끝은 약 48%
  - 사진: 가로 10%~90%, 위쪽은 높이의 약 6%, 아래쪽은 약 72%(포켓 뒤로 숨음)
  - 이름: 신랑 부모 줄 (x 12%, y 74%), 신랑 이름 (x 24%, y 79%), 신부 부모 줄 (x 52%, y 87%), 신부 이름 (x 64%, y 92%)
- 하트 1(이중 하트): 봉투 박스 오른쪽 위, 덮개 꼭짓점 오른쪽(x 중심 약 68%, 위쪽 약 -4%)
- 페이지 상단 여백: 하트가 잘리지 않도록 약 0.12S
- 인사말·하트 2는 2차 값 유지

## 수용 기준

1. 이름 4쌍·신랑·신부 이름이 봉투에 렌더링된다
2. 인사말 문단과 `사랑을 담아♡`, `{신랑}, {신부} 드림`이 렌더링된다
3. 하트 스티커 2개가 렌더링되고 장식용(aria-hidden)이다
4. 모바일(375px) 폭에서 가로 스크롤이 없다
5. `npm run lint`, `npx tsc -b`, `npm test`, `npm run build` 통과
