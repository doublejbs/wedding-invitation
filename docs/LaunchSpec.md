# 모바일 청첩장 — 런칭 디자인 시안 스펙

## 목표

제품 발표 페이지 문법(큰 타이포, 넓은 여백, 섹션별 배경 전환, 스크롤 연동 연출)을 빌린 두 번째 청첩장 디자인 시안.
**톤은 진지하고 우아하게** — 제품 발표 형식만 빌리고 농담은 넣지 않는다.
특정 회사의 로고·상표·고유 폰트·문구는 사용하지 않는다.

## 구조

- 기존 봉투 디자인(`index.html`)은 그대로 둔다
- Vite 멀티 페이지: `launch.html` → `src/LaunchMain.tsx` → `LaunchPageView`
- 이름 등 공통 데이터는 `src/data/InvitationData.ts`를 재사용하고, 예식 정보 등 새 데이터는 같은 파일에 추가
- 시안이므로 사진은 **플레이스홀더**(그라데이션 + "사진 N" 라벨)로 처리하고, 데이터에서 경로만 바꾸면 실제 사진이 들어가게 한다

## 디자인 토큰

- 폰트: Pretendard(한글, npm `pretendard@1.3.9` 가변 폰트를 번들에 포함), Inter(영문, Google Fonts)
- 배경: 섹션마다 검정(#000) / 흰색(#fff) / 연회색(#f5f5f7)을 섞는다
- 글자: 검정 배경 #f5f5f7, 흰 배경 #1d1d1f, 보조 #86868b
- 강조색: 파랑 #0071e3 (버튼, 링크)
- 큰 제목 48~56px / 굵기 700 / 자간 -0.02em, 본문 17px / 줄간격 1.5
- 섹션 상하 여백 약 120px, 좌우 24px

## 예시 데이터 (추가)

- 예식: 2027년 4월 17일 토요일 오후 1시
- 장소: 더채플웨딩홀 3층 그랜드볼룸 / 서울특별시 ○○구 ○○로 123
- 연애 시작일: 2022년 3월 1일 (함께한 날 계산용)
- 신랑·신부 계좌(예시 번호)

## 섹션 (위→아래)

1. **히어로** (검정)
   - 화면 가득 `The Wedding.` (Inter, 아주 크게), 아래 "2027년 봄, 두 사람이 시작합니다."
   - 스크롤하면 sticky로 고정된 사진이 작은 카드 크기에서 화면 가득으로 커진다
2. **Introducing** (검정)
   - "신랑 {신랑} 그리고 신부 {신부}. / 이제, 하나의 이름으로." 문장이 스크롤에 따라 단어 단위로 회색 → 흰색으로 밝아진다
3. **하이라이트** (연회색)
   - 가로 스크롤 카드 4장(scroll-snap): 첫 만남 / 함께한 계절 / 프러포즈 / 새로운 시작. 카드마다 사진 + 제목 + 한 줄
4. **숫자로 보는 우리** (흰색)
   - 큰 숫자 3개, 화면에 들어오면 카운트업: 함께한 날(연애 시작일 기준 자동 계산), 함께 본 계절 수, 다가올 날(예식까지 D-day)
5. **갤러리** (검정)
   - 상단 세그먼트 버튼 "스튜디오 / 스냅 / 일상" → 선택에 따라 사진 세트 전환(페이드)
   - 사진 아래 작은 점 페이지네이션, 좌우 스와이프
6. **기술 사양 = 예식 정보** (흰색)
   - 두 열 사양표: 일시 / 장소 / 주소 / 식사 / 주차. 줄 사이 얇은 구분선
7. **비교하기** (연회색) — 진지한 톤
   - 신랑·신부 두 열 비교표: 태어난 곳, 좋아하는 계절, 좋아하는 것 등 담백한 소개. 마지막 줄 "앞으로 — 함께"
8. **오시는 길** (흰색)
   - 지도 자리(플레이스홀더 박스), 주소, 복사 버튼, 네이버 지도 / 카카오맵 / 티맵 버튼(검색 URL로 새 탭)
   - 지하철·버스·주차 안내 텍스트
9. **참석 예약** (검정)
   - 파란 둥근 버튼 "참석 의사 전하기" → 시트(모달)에 이름·참석 여부·인원·식사 여부 입력 폼 (**시안: 제출 시 "시안에서는 저장되지 않습니다" 안내만**)
   - "마음 전하실 곳" 접이식(신랑측/신부측), 계좌 복사 버튼
10. **푸터** (연회색)
    - 작은 회색 글씨 각주: "* 본 청첩장의 사진과 문구는 시안용 예시입니다." / 두 사람 이름, 날짜

## 상단 내비게이션

- 스크롤 시 상단에 얇은 반투명 바(backdrop-filter blur): 왼쪽 "{신랑} & {신부}", 오른쪽 파란 작은 버튼 "참석 예약"(9번 섹션으로 이동)

## 연출 규칙

- 스크롤 연동은 `IntersectionObserver` + 스크롤 진행도(sticky 컨테이너 내 0~1)로 구현, 라이브러리 없이
- 섹션 진입 시 제목은 아래에서 위로 살짝 떠오르며 나타남(opacity + translateY 24px, 0.8s)
- `prefers-reduced-motion: reduce`이면 모든 연출을 끄고 최종 상태로 표시
- 375px 폭에서 가로 스크롤 없음(하이라이트 카드 영역의 의도된 가로 스크롤 제외)

## 수용 기준

1. `launch.html`에 10개 섹션이 순서대로 렌더링된다(각 section에 aria-label)
2. 함께한 날·D-day가 기준일로부터 올바르게 계산된다(계산 함수 단위 테스트)
3. 갤러리 세그먼트 버튼 클릭 시 사진 세트가 바뀐다
4. 참석 예약 버튼을 누르면 폼 시트가 열리고, 제출하면 시안 안내가 보인다
5. 기존 봉투 디자인 테스트가 계속 통과한다
6. `npm run lint`, `npx tsc -b`, `npm test`, `npm run build` 통과
