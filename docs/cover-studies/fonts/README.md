# 글꼴

## NanumYeoReumGeurSsi-ksx1001.woff2 — 나눔손글씨 여름글씨

- 출처: 네이버 클로바 나눔손글씨 (Copyright © 2019 NAVER Corporation. All rights reserved. Font created by CLOVA AI OCR Team.)
- 네이버가 무료로 배포하는 오픈 라이선스 글꼴이다(웹에 넣어 배포해도 되는 것을 사용자가 확인함, 2026-11-26). 조건은 네이버의 나눔글꼴 라이선스 원문을 따른다 (https://hangeul.naver.com).
- 원본 TTF(약 5MB, 한글 11,172자)에서 KS X 1001 한글 2,350자와 영문·숫자·기호만 남겨 웹용 woff2로 줄인 것이다. 글자 모양은 바꾸지 않았다.
- 다시 만들기: `python3 scripts/BuildGuestFont.py "<나눔손글씨 여름글씨.ttf>"` (원본 TTF는 저장소에 넣지 않는다).
- 쓰는 곳: 받는 사람 이름 링크(`?to=이름`)의 커버 손글씨 이름 (docs/SectionsSpec.md 2-0).
