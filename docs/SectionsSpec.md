# 영역 기획 — 커버 톤 기준

커버(`GreenhouseCover.html`)의 톤을 나머지 일곱 영역에 그대로 옮긴다. 인사말과 사진은 이미 만든 것을 커버 기준으로 다시 맞추고, 남은 다섯 영역은 새로 만든다.
이전 스펙(`Spec.md`, `LaunchSpec.md`, `EditorialSpec.md`, `CollageSpec.md`, `ScrapbookSpec.md`)의 영역 기획은 이 문서로 대체한다.

## 1. 커버에서 가져오는 규칙

| 커버의 장치 | 다른 영역에서 쓰는 법 |
|---|---|
| 제목 `WEDDING INVITATION` 아래 이름 줄 — 3칸 그리드(`1fr auto 1fr`), 반지 그림이 중심축 | 영역 제목 `.section-title` (인사말은 제목 없이 시작). 영문 단어 – 크레파스 그림 – 한글 단어 |
| `Seo Jinyong 💍 Jang Harim` — 두 이름이 축을 사이에 두고 마주 봄 | 신랑측 ↔ 신부측처럼 짝이 있는 정보는 모두 이 배치 |
| `2027 / 03.06` ↔ `토요일 오후 5시 / 식물관PH` — 왼쪽은 큰 숫자, 오른쪽은 오른쪽 정렬 글자 | 숫자·핵심 한 가지를 왼쪽에 크게, 풀이를 오른쪽에 작게 |
| Archivo 500, 자간 -0.02em, 잉크 `#161616`, 보조 `#4d4d4a`, 종이 `#fbfbf8` | 전 영역 동일. 굵기로 강조하지 않고 크기 두 단계(큰 글자 22–26px, 본문 15px)만 쓴다 |
| 그림자·테두리·면 없음 | 구분선, 카드, 버튼 테두리, 배경색 블록 없음(인사말 영역만 예외로 검은 면). 영역 사이는 여백(위 48px, 아래 56px)만 |
| 크레파스 그림 하나 | 영역마다 제목의 그림 하나만. 본문에는 그림을 더 넣지 않는다 |

누를 수 있는 글자는 테두리 버튼 대신 **크레파스 밑줄**(`--pencil` 연필색, 두 번 겹쳐 그은 선)로 표시한다.
고른 항목은 **크레파스 동그라미**로 두른다. 이 두 가지가 전 영역 공통 조작 표시다.

## 2. 영역별 기획

### 2-1. 인사말 (제목 없음)

인사말 영역만 예외로 **검은 면**(`#000`, 사용자 요청)이다. 구성은 우표 한 장 → 종이색 글자의 가운데 정렬 인사말. 제목과 서명 줄은 없다.

- 배경: 순수한 검정 `#000`(우표 이미지 원본의 배경과 같은 값). 화면 전체 폭으로 깔고, 내용은 다른 영역과 같은 440px 기둥 안에 둔다. PC에서는 종이색 페이지를 가로지르는 검은 띠가 된다. 위(커버)·아래(사진 영역)와는 반듯한 수평선으로 끊긴다(그라데이션·그림자 없음). `<section>`에 `data-tone="dark"`.
- 우표: 사용자가 준 흰 종이 우표 이미지(`textures/stamp-frame.png`, 595×860, 톱니 포함, 바깥과 구멍은 투명) 한 장 안에 종이 청첩장 표지와 같은 사진 두 장을 같은 구도로 위아래로 넣는다(컬러). 위는 `photo-12`(역광 들판에서 신랑이 웃는 신부의 볼에 얼굴을 댄 모습, 얼굴·어깨), 아래는 `photo-04`(파란 하늘 아래 나란히 서서 신부가 신랑을 올려다보는 상반신, 부케 포함). 사진 창은 종이 가장자리에서 네 변 모두 62px(원본 픽셀) 안쪽: 톱니가 18–19px 파고들어 톱니 안쪽으로 약 43px(종이 폭의 7%) 흰 여백이 남는다. 이 창을 같은 크기 두 칸(각 471×361)으로 나누고 사이에 종이 흰 띠 14px(종이 폭의 2.4%)를 둔다. CSS로는 두 칸 모두 왼쪽 10.420%, 폭 79.160%, 높이 41.977%, 위 칸 top 7.209%, 아래 칸 top 50.814%. 칸이 사진을 잘라 보이고, 사진은 칸 폭 기준 %로 확대·이동한다(12번 원본 x 520–1060·y 294–708, 04번 원본 x 510–1090·y 430–874를 칸에 꽉 채움).
- 크기: 우표 폭 `clamp(108px, 32vw, 140px)`(390px 화면 약 125px, 320px 화면 108px), `aspect-ratio: 595 / 860`으로 이미지가 오기 전에도 자리를 잡는다.
- 여백: 영역 위 72px, 아래 80px(검은 면이 답답하지 않게 다른 영역보다 넉넉히), 우표와 인사말 사이 52px.
- 글자: 종이색(`#fbfbf8`), `.prose` 크기 그대로. 인사말 문단이 마지막 요소다.
- 등장 효과 없음. 예전의 CSS mask 우표 두 장과 크레파스 외곽선은 뺐다.
- 인사말은 6줄 이내, 한 줄 16자 안팎으로 끊는다. 문구는 초안이라 확정이 필요하다.

```
  ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■  (검은 면)
           ┌ 우표 ─────┐
           │  12번     │
           │  04번     │
           └───────────┘
     겨울 끝자락에 만난 두 사람이
              …
```

### 2-2. 사진 (다시 맞춤) — 필름 스트립 (`PhotosFilm.html`)

사용자가 준 필름 스트립 참고 이미지처럼, 사진 14장을 세 줄의 35mm 필름에 담아 검은 인사말 띠 바로 아래에서 늘어뜨린다. 하트 모자이크(`PhotosMosaic.html`)를 대신한다. 사진 영역에는 글자를 넣지 않는다(사용자 요청). 필름 가장자리의 프레임 번호와 인쇄 글씨는 CSS로만 그린다.

- 세 줄은 화면 좌우 12px 여백 안(최대 480px)을 8px 간격으로 나눠 채운다. 스트립 폭의 1%를 단위(u)로 쓴다.
- 폭 방향: 테두리 14u + 사진 72u + 테두리 14u. 퍼포레이션 7u×5u, 프레임(72u×108u, 2:3)마다 8개.
- 왼쪽 3장, 가운데 6장, 오른쪽 5장. 시작 높이(46u·12u·78u)와 프레임 번호 구간이 줄마다 달라 끝이 엇갈린다.
- 가로 사진은 두 사람 위치에 맞춰 `--pos`로 잘라 쓴다. 누르면 원본을 크게 본다.

### 2-3. 예식 안내 — `CEREMONY 🌺 예식 안내`

- 그림: 커버 버진로드의 붉은 꽃 한 송이.
- 구성 (위에서 아래로)
  1. 혼주 줄: 커버 이름 줄과 같은 배치. 왼쪽 `서○○ · ○○○ 의 아들 진용`, 오른쪽 `장○○ · ○○○ 의 딸 하림`. `GROOM`/`BRIDE` 라벨은 쓰지 않는다.
  2. 날짜 줄: 커버 아래쪽과 같은 배치. 왼쪽에 `D-107`처럼 남은 날을 큰 숫자로(매일 바뀜, 당일은 `TODAY`, 지나면 숨김), 오른쪽에 `2027년 3월 6일 토요일` / `오후 5시`.
  3. 안내 문장: 가운데 정렬 2–3줄. 식사, 예식 시작 전 도착 안내 등. 표로 만들지 않고 인사말과 같은 문장체.
- 달력 그림은 넣지 않는다 (템플릿 느낌).

```
      CEREMONY  🌺  예식 안내

서○○ · ○○○            장○○ · ○○○
의 아들 진용             의 딸 하림

D-107              2027년 3월 6일 토요일
                              오후 5시

      예식 후 온실에서 식사를 대접합니다.
```

### 2-4. 오시는 길 — `LOCATION 🏡 오시는 길`

- 그림: 커버 온실을 작게 줄인 크레파스 온실.
- 구성
  1. 장소 줄: 왼쪽 `식물관PH`(큰 글자), 오른쪽 주소 두 줄(오른쪽 정렬). 주소를 누르면 복사되고 그 자리 글자가 잠깐 `복사했어요`로 바뀐다.
  2. 지도 앱: `네이버 지도` `카카오맵` `티맵` 세 단어를 한 줄에, 크레파스 밑줄. 지도 이미지는 넣지 않는다.
  3. 교통: `지하철` `버스` `주차` `셔틀`(있으면). 항목 이름은 보조색 작은 글자, 바로 아래 문장. 표·아이콘 없음. 훑어보는 정보라 왼쪽 정렬 (가운데 정렬은 좁은 화면에서 줄바꿈이 들쭉날쭉했다).
- 지도 이미지를 뺀 이유: 지도 타일은 종이 톤과 가장 안 맞는 요소이고, 하객은 어차피 지도 앱으로 넘어간다.

### 2-5. 마음 전하실 곳 — `GIFT ✉️ 마음 전하실 곳`

- 그림: 크레파스 흰 봉투에 금색 봉인.
- 구성
  1. 한 줄 문장: "참석이 어려우신 분들을 위해 계좌번호를 적어 둡니다."
  2. `신랑측` ↔ `신부측` 두 단어가 마주 봄. 하나를 누르면 크레파스 동그라미가 그려지고 그쪽 계좌가 아래에 펼쳐진다. 처음에는 접혀 있다.
  3. 계좌 한 건 = 두 줄. 윗줄 보조색 `신랑 서진용`, 아랫줄 `○○은행 000-0000-0000-00`. 아랫줄을 누르면 복사되고 `복사했어요`로 잠깐 바뀐다.
- 카카오페이·토스 송금 링크는 받으면 계좌 옆에 단어로 추가한다.

### 2-6. 참석 여부 — `RSVP ✓ 참석 여부`

- 그림: 붉은 크레파스로 그은 체크 표시.
- 구성: 질문 하나에 한 줄. 선택지는 마주 보는 두 단어, 고르면 크레파스 동그라미.
  1. `신랑측` ↔ `신부측`
  2. `참석해요` ↔ `마음만 보내요`
  3. 이름: 크레파스 밑줄 한 줄 위에 직접 입력
  4. 인원: `−  2  +` (참석일 때만 보임)
  5. 식사: `식사해요` ↔ `식사 안 해요` (참석일 때만 보임). 참석을 골랐으면 식사도 골라야 보내진다
  6. `보내기` — 크레파스 밑줄 단어. 보낸 뒤에는 폼 자리에 "전해졌어요. 고맙습니다." 한 문장만 남는다.
- 입력칸 상자, 필수 표시(*), 드롭다운은 쓰지 않는다. 선택지 단어는 평소 연필 밑줄, 고르면 동그라미. 답하지 않은 줄(이름, 참석일 때 식사 포함)은 밑줄만 붉은색으로 바뀐다.
- 저장: 구글 앱스 스크립트(`scripts/RsvpSheet.gs`)로 구글 시트에 한 줄씩 기록 (무료, 두 분이 시트로 바로 확인). 같은 기기에서 같은 이름으로 다시 보내면 덮어쓴다 (한 기기로 다른 이름을 보내면 새 줄). 주소(`RSVP_ENDPOINT`)를 넣기 전에는 저장하지 않고 "시안이라 아직 저장되지는 않아요."라고 알린다.

### 2-7. 마무리 — `THANK 💍 YOU`

- 그림: 커버와 같은 반지(반짝임 포함). 커버 이름 줄 `Seo Jinyong 💍 Jang Harim` 가운데의 반지와 처음·끝이 짝이 된다.
- 구성
  1. 마지막 한 문장, 가운데 정렬.
  2. `청첩장 보내기` ↔ `주소 복사` 마주 보는 두 단어, 크레파스 밑줄. `청첩장 보내기`는 휴대폰 기본 공유 창을 연다 (카카오톡 전용 공유는 카카오 앱 키가 있어야 해서 보류). 공유 창이 없는 브라우저에서는 `주소 복사`만 가운데에 남는다.
- 이름은 다시 적지 않는다 (커버, 혼주 줄에 이미 나온다).
- 제작 표기, 각주, 저작권 문구는 넣지 않는다.

## 3. 그림 배정

| 영역 | 그림 | 색 |
|---|---|---|
| 커버 | 반지, 온실 | 금, 초록·붉은색 |
| 인사말 | 없음 (우표 사진, 검은 면) | – |
| 사진 | 없음 (사진만, 글자 없음) | – |
| 예식 안내 | 꽃 한 송이 | 붉은색 |
| 오시는 길 | 작은 온실 | 초록 + 연필선 |
| 마음 전하실 곳 | 봉투 | 연필선 + 금 |
| 참석 여부 | 체크 | 붉은색 |
| 마무리 | 반지 | 금 |

제목 그림의 색은 초록 → 붉은색 → 초록 → 금 → 붉은색 → 금 순으로, 같은 색이 연달아 나오지 않는다.

## 4. 만드는 방식

- 인사말은 기존 파일(`GreetingCard.html`)을 고치고, 사진은 `PhotosFilm.html`(필름 스트립)로 새로 만들었다(예전 커버플로, 흩어 놓은 배치, 하트 모자이크는 지움).
- 새 영역은 `docs/cover-studies/`에 파일 하나씩: `CeremonyInfo.html`, `Directions.html`, `GiftAccounts.html`, `Rsvp.html`, `Closing.html`.
- `.section-title`, 크레파스 밑줄, 크레파스 동그라미, 복사 동작은 공용 키트(`SectionKit.css`, `SectionKit.js`)에 두고 모든 영역이 그대로 쓴다.
- `scripts/BuildInvitation.py`는 영역 목록(`SECTIONS`)을 순서대로 합치고 키트를 한 번만 넣는다.
- 순서는 한 영역씩 확정: 인사말 → 사진 → 예식 안내 → 오시는 길 → 마음 전하실 곳 → 참석 여부 → 마무리.
- 움직임은 `prefers-reduced-motion`일 때 끈다. 누르는 글자는 높이 44px 이상을 확보한다.

## 5. 받아야 할 정보

| 영역 | 필요한 것 |
|---|---|
| 인사말 | 확정 문구 |
| 예식 안내 | 혼주 성함(표기 순서, 고인 표기 여부), 식사 방식, 안내하고 싶은 문장 |
| 오시는 길 | 식물관PH 주소, 지하철·버스·주차·셔틀 정보 |
| 마음 전하실 곳 | 계좌(몇 분까지 넣을지), 간편송금 링크 여부 |
| 참석 여부 | 받을 항목 확정, 응답을 받을 구글 계정 |
| 마무리 | 마지막 문장 |

## 6. 정해야 할 것

1. 혼주 줄을 좌우로 마주 보게 놓을지. 예전에 "Groom/Bride 두 칸"은 레퍼런스 베끼기라 빼기로 했는데, 이 안은 라벨 없이 커버 이름 줄을 되풀이하는 것이라 다르다고 보고 넣었다. 싫으면 가운데 두 줄로 바꾼다.
2. 오시는 길에 지도 이미지를 정말 뺄지.
3. 계좌를 접어 둘지, 처음부터 펼칠지.
4. 참석 여부 저장을 구글 시트로 할지.
5. 인사말 끝에 서명 줄을 넣을지. → 넣지 않기로 함.
6. 사진에 위치 점과 크게 보기를 넣을지. → 커버플로를 다른 배치로 바꾸면서 위치 점은 뺐고, 크게 보기는 남김.
